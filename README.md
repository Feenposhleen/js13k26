# js13k26

Game submission for the 2026 edition of the js13k jam, a jam with the twist that the final game must be 13kb or less zipped.

### Tech

Vector assets created in the included edtor, drawn and pre-rendered at runtime through an offscreen canvas. Two-threaded, ping-pong buffering WebGL2 rendering with full screen shader support.

Audio through the Web Audio API, with songs and effects created using the included editor.
